Story:

You are a HILL INSPECTOR attempting to ensure that each hill is stable and that there's nothing unusual inside. Peek inside each hill and make sure that it's all dirt!

Controls:

W/A/S/D: Move Forward/Left/Backward/Right

Select local CSV File:

Wow Criteria

I created a custom hill generator that creates a hill of a random height given a position. I give this function some default values and generate the world with them, and you can re-generate or add to the world using those same parameters. The algorithm adds to any blocks already placed in the world, so generation can get pretty crazy if you spam it a bunch! I also added world exporting and importing with CSV files. This is unsecure because I implemented it 4 minutes before the deadline. Sorry!
